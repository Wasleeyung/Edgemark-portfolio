Module 01

Modal Analysis & Comfort Suite

Dynamic modal extraction and human comfort assessment from live ETABS models — per ISO 10137:2007, BS 6472-1:2008, and BS EN 1998-1 (EC8).

  • Building density: total mass (kg/tonnes), volume (m³), average density (kg/m³)
  • Mass source correction: prevents double-counting Live load
  • Natural periods T, cyclic frequencies f, circular frequencies ω, eigenvalues
  • Mass participation ratios (UX, UY, UZ, RX, RY, RZ) + cumulative 90% check
  • Torsional irregularity ratio T_torsion/T_sway — flags > 1.2 (EC8) automatically
  • ISO 10137 / BS 6472 peak acceleration benchmarks — operating theatre to office
  • Auto-generated HTML + text comfort reports; offline demo dataset included
ISO 10137 BS 6472 EC8 Compliance
Module 02

BS Code Load Combinations Generator

Automatically creates the full suite of Ultimate (ULS) and Serviceability (SLS) combinations in ETABS per BS 8110, BS 8004, BS 6399, and BS 8007.

  • Dead, Super Dead (Gk), Live (Qk), Wind X/Y with ± reversals
  • Soil lateral pressure, hydrostatic water, variable surcharge
  • ULS Linear Add + Envelope combinations auto-generated
  • SLS serviceability combos for deflection and cracking checks
  • Writes directly into active ETABS model via COM — zero manual data entry
BS 8110 BS 8004 BS 6399 BS 8007
Module 03

Automated 15m Pile Modeling Tool

Hybrid piled-raft foundation generator — reads live ETABS reaction forces and generates structurally sized, code-spaced piles directly into the model.

  • D=600mm circular pile section (PILE_D600) auto-defined in ETABS
  • Reads real vertical reaction F3 from selected load combo
  • Concentrated piles under columns/walls + distributed across mat footprint
  • Strict spacing enforcement: ≥ 1.5D (≥ 0.90m) — zero clash, zero overlap
  • 15m-deep pile elements drawn via AddByCoord into new Basement story
  • Point spring properties assigned to pile tips; view refreshed automatically
Piled-Raft D600mm Spring Stiffness
Module 04

Wall Pier Label Automation (Bottom-Up)

Automatically identifies, groups, and assigns unique pier labels (P1 → Pn) to all vertical shear wall elements across every story from bottom to top.

  • Scans all wall Area objects across all stories automatically
  • Groups walls into continuous vertical stacks by plan footprint (X, Y)
  • Generates unique pier labels P1, P2… Pn per wall stack
  • Creates labels in ETABS database, assigns to every wall element
  • Refreshes viewport and displays summary assignment table

Nonlinear P-Delta & Staged Construction

Interactive GUI configurator for complete nonlinear analysis: gravity P-Delta base cases, wind lateral continuations, and story-by-story staged sequences.

Module 06

STRUCTMOD — Stiffness Modifier Manager

Windows desktop app managing SLS/ULS stiffness modifier schedules across frame and shell members, with automated SLS model duplication from the active ULS model.

  • Editable frame and shell modifier schedules (beams, columns, walls, slabs)
  • Applies modifiers directly to ETABS property definitions via COM API
  • Auto rollback on write failure — existing values restored if error occurs
  • Creates _sls.edb copy from open ULS model — prevents accidental overwrite
  • Export modifier schedule as JSON preset or CSV for review
ULS / SLS Stiffness Modifiers Auto Rollback
Module 07

Rigid Link Engine & Load Correction

Two precision tools: a 6-DOF rigid link generator for horizontal in-plane connections, and a Null Frame load correction engine that fixes misassigned gravity loads.

  • Defines AUTO_RIGIDLINK 6-DOF fully rigid property automatically
  • Strict filter — omits Null frames, dummy lines, and non-structural sections
  • In-plane only: Z_beam == Z_col enforcement, zero Z-axis links
  • Null Frame load correction: transfers Live → Super Dead on Null sections
  • Auto timestamped .EDB backup before every modification
  • Dry-run mode: inspect load counts without touching model data
