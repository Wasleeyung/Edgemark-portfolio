## ✅ Features

- Responsive design (mobile, tablet, desktop)
- Smooth scroll navigation with active link highlighting
- Scroll-triggered animations (AOS-style, no dependency)
- Animated stat counters on hero section load
- Project portfolio filter (All / Structural / Automation / Highrise)
- Mobile hamburger menu
- Contact form with submit feedback
- Back-to-top button
- Marquee skills strip (pauseable on hover)
- Pure HTML + CSS + Vanilla JS — zero dependencies (except Google Fonts + Font Awesome CDN)

---

## 🚀 To Run

Simply open `index.html` in a browser — no build step required.

For production deployment:
- Host on **Netlify**, **Vercel**, or any static hosting
- Add a real domain: e.g. `edgemarkconsulting.com`
- Wire up contact form to **EmailJS** or a backend endpoint
